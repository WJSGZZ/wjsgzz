I build small tools that pair one concrete problem with an AI agent that can see it through:

- **PBlossom**: casts I Ching hexagrams and reads the traditional Chinese calendar. [Try it](https://wjsgzz.github.io/PBlossom/) (Chinese UI).
- **Praxis**: a math-modeling partner that goes from problem statement to a model you can check and a report you can defend.
- **Ubinam**: tells you where and when a photo was taken, and how sure it is.
- **MayoSocratic**: a skill that asks before it answers.
